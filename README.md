# Surgy Store — MVP de la web (demostración)

Versión de demostración del 18-nov-2026 de la nueva web de Surgy Store (Corporación Surgystore 077 C.A., Caracas, Venezuela): explorador 3D por capas (columna, cráneo y cerebro), catálogo sin precios y solicitud de cotización.

- No es la web oficial. No está indexada en buscadores.
- Las marcas son de sus dueños.
- Contenido educativo; modelos 3D ilustrativos. La capa de células y los nervios de la columna son ilustraciones.
